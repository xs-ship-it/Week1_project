Authcore

What problem does it solve?Small internet providers are managing authentication with scripts and spreadsheets, with the only plattforms available to them being very expensive. AuthCore will bring RADIUS authentication, accounting, and billing into one system so they always know who's connected

My approachAuthCore is built around AAA, which stands for Authentication, Authorization, and Accounting. It is a framework that controls who gets access to a network, what they are allowed to do once connected, and tracks their usage for billing purposes. Every session on the network passes through all three stages, which makes it the right foundation for a system that needs to be both secure and billable.

I plan to build each layer of AAA in order. Get authentication solid first, then enforce authorization rules, then wire in accounting so usage data flows cleanly into billing.

(video: how AAA works)

The hardest thing I expect to learnRADIUS is an old protocol with a lot of vendor-specific quirks. I expect the biggest challenge to be handling how different routers interpret the same standard differently.
