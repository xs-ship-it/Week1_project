Project

AuthCore

RADIUS authentication server with billing integration for small ISPs.

Problem

Small internet providers are managing authentication with scripts and spreadsheets, with the only platforms available being very expensive. AuthCore brings RADIUS authentication, accounting, and billing into one system so they always know who is connected.

Approach

AuthCore is built around AAA — Authentication, Authorization, and Accounting. It is a framework that controls who gets access to a network, what they are allowed to do once connected, and tracks their usage for billing. I plan to build each layer in order: get authentication solid first, then enforce authorization rules, then wire in accounting so usage data flows cleanly into billing.

Hardest challenge

RADIUS is an old protocol with a lot of vendor-specific quirks. The biggest challenge will be handling how different routers interpret the same standard differently.
